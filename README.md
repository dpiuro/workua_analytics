# Work.ua Analytics

## 📌 Project Overview

**Work.ua Analytics** is a data analysis tool that collects and processes job listings from [Work.ua](https://www.work.ua/). It provides insights into the labor market, popular technologies, required skills, and hiring trends.

## 🚀 Features

- **Job Data Collection** – Automated scraping of job postings from Work.ua.  
- **Data Cleaning & Processing** – Structured storage of job data for analysis.  
- **Visualization & Reporting** – Generate reports on job trends, salary distribution, and skill demand.  
- **Keyword & Skill Analysis** – Identify the most in-demand technologies and skills.  

## 🛠️ Technologies Used

- **Python** – Core language for data collection and analysis.  
- **Pandas & NumPy** – Data manipulation and processing.  
- **BeautifulSoup & Scrapy** – Web scraping tools for extracting job data.  
- **Matplotlib** – Data visualization and reporting.
